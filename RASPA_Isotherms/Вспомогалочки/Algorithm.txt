Структура: 

RASPA_tests/
├── main_experiment.py           (Скрипт запуска, запускаем только его)
├── convert_to_raspa.py          (Скрипт обработки, подготовки)
├── simulation.input.template    (Шаблон настроек - код на RASPA)
├── plot_data.py                 (Для вывода теплоты адсорбции и построения изотерм адсорбции)
├── combine_movie.py             (Нужен для визуализации симуляции в Ovito Basic - совмещает каркас мофа и газ, создаст FULL_MOVIE.pdb)
├── run.sh                       (НЕ ИСПОЛЬЗУЕТСЯ, нужен для пошаговой симуляции - фикс T и p)
├── void.input.template          (ПОКА НЕ РАБОТАЕТ, Шаблонный файл RASPA конкрутно для гелия, чтобы посчитать HeliumVoidFraction)
├── MOF/                         (ПАПКА ДЛЯ НАШИХ СТРУКТУР)
│   ├── MOF5.cif
│   └── Any_Other_MOF.cif
└── ForceField/                  (ПАПКА ДЛЯ СИЛОВЫХ ПОЛЕЙ И ГАЗОВ)
    ├── force_field_mixing_rules.def
    ├── pseudo_atoms.def
    ├── force_field.def
    └── Any_GAS.def

Инструкция для пользователя:
1. Поместить .cif файл с каркасом в папку MOF/.
2. Убедитесь, что в папке ForceField/ лежат 3 необходимых .def файла (правила смешения и псевдоатомы): 
   force_field_mixing_rules.def, force_field.def, pseudo_atoms.def.
3. В main_experiment.py поменять в самом начале название MOF и газа, и, если нужно, значения температуры и давления.
4. Перед запуском сделать: export RASPA_DIR=${HOME}/RASPA/simulations/
    Запуск: python3 main_experiment.py
5. Выполнить python3 plot_data.py для вывода теплоты адсорбции для каждой температуры, построения изотерм адсорбции isotherms.png.

Как работает main_experiment.py (менеджер):

Логика блоками:
1. Настройки: Вы задаете, какой MOF, какой газ и при каких условиях (T, P) считать.
2. Подготовка: Вызывает второй скрипт, чтобы один раз подготовить структуру и найти файл газа.
3. Цикл эксперимента (Isotherms):
    - Бежит по температурам и давлениям.
    - Для каждой точки создает папку.
    - Настраивает файл simulation.input (меняет T, P, включает/выключает кино).
    - Запускает RASPA.
    - Сразу читает результат (сколько адсорбировалось) и запоминает.
4. Сохранение: Записывает все собранные данные в final_results.csv.

Построчный разбор:
Импорты (import ...): Подключает библиотеки для работы с файловой системой (os, shutil), запуска программ (subprocess) и работы с CSV таблицами.
Блок НАСТРОЙКИ ЭКСПЕРИМЕНТА: Здесь вы руками вписываете вводные данные (MOF5, CO2, список температур и давлений).
Пути (BASE_DIR, RASPA_DIR): Скрипт определяет, где он находится и где установлена RASPA (через переменные окружения).
def check_setup(): Проверка безопасности. Если RASPA не установлена или файла с MOF нет — скрипт сразу остановится и скажет об этом.
def parse_output(...): Функция-"читатель".
    Она открывает файл .data, который создала RASPA.
    Ищет строки Average loading absolute (загрузка) и Heat of desorption (теплота).
    Возвращает эти числа в программу.
def run_isotherms() — Самый главный блок:
    subprocess.call([... "convert_to_raspa.py" ...]): Вызывает второй скрипт, чтобы подготовить simulation_structure.cif и CO2.def.
    with open("simulation.input.template"...): Читает шаблон настроек в память.
    for temp in ... for press_bar in ...: Два цикла. Перебираем все комбинации температур и давлений.
    os.makedirs(point_dir): Создает папку для конкретной точки (например, Results/298K/1.0bar).
    shutil.copy(...): Копирует в эту папку готовый CIF, файл газа и все файлы из ForceField.
    movie_flag = ...: Логика: если давление минимальное — пишем кино (yes), если нет — экономим место (no).
    sim_content = template_content.replace(...): Берет текст шаблона и заменяет слова-заглушки (TEMP_PLACEHOLDER, REPLACE_ME) на реальные числа и имена.
    subprocess.run(...): Запускает RASPA (bin/simulate) внутри созданной папки.
    parse_output(...): Сразу после расчета читает результат.
def save_csv(...): Создает файл final_results.csv и аккуратно записывает туда заголовки и полученные данные.
if __name__ == "__main__":: Точка входа. Запускает проверки, потом основной цикл, потом сохранение.



Как работает convert_to_raspa.py (подготовка):

Логика блоками:
1. Импорт PyEQEq: Пытается подключить библиотеку зарядов. Если не вышло — не падает, а просто предупреждает (будут нули).
2. Обработка CIF (clean_and_charge_cif):
    - Читает исходный файл.
    - Выкидывает всё лишнее, оставляет только координаты.
    - Очищает имена атомов (превращает Zn1, Zn2 просто в Zn для силового поля).
    - Сохраняет временный чистый файл.
    - Натравливает на него PyEQEq для расчета зарядов.
3. Поиск газа (handle_gas_file):
    - Смотрит, есть ли файл газа в локальной папке ForceField.
    - Если нет — ищет его глубоко в недрах установленной RASPA.
    - Копирует найденный файл в корень, чтобы RASPA могла его прочитать.

Построчный разбор:
Блок try ... except ImportError: Безопасное подключение. Если вы не установили pyeqeq, переменная HAS_PYEQEQ станет False, и программа пойдет по запасному пути (нули).
def handle_gas_file(...):
    glob.glob(...): Мощная команда поиска файлов. Ищет CO2.def везде, где только можно.
    shutil.copy(...): Копирует найденный файл сначала в папку-архив ForceField (на будущее), а потом в текущую папку (для работы).
def clean_and_charge_cif(...):
    cell_keys: Список параметров ячейки (a, b, c, углы), которые надо найти в файле.
    Цикл for line in lines: Читает файл построчно.
    Парсинг атомов: Самая сложная часть. Ищет колонки label, fract_x и т.д.
    clean_type = ...: Логика очистки имени. Если атом называется Zn123, команда удаляет цифры, остается Zn. Это критически важно для UFF.
    Запись temp_clean.cif: Создает идеально правильный CIF файл с зарядами 0.0.
    Блок расчета зарядов:
        Если HAS_PYEQEQ активно: вызывает run_eqeq(). Эта функция берет файл, считает электростатику и перезаписывает файл уже с реальными зарядами.
        Если нет: просто копирует файл с нулями.
if __name__ == "__main__"::
    Принимает аргументы командной строки (например, ./script.py MOF5.cif CO2).
    Запускает по очереди функцию обработки CIF и функцию поиска газа.
